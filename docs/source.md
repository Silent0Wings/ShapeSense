# Source map

Every external asset and dataset, with the one local copy kept of each.
Duplicates (identical by content hash) were deleted on 2026-10-19; see
"Removed duplicates" at the bottom. `data_set/` is git-ignored, so every
dataset is re-downloadable from its origin link below.

## Datasets used in the unified dataset

| # | Origin | Local folder | License | Contents (verified on disk) |
|---|---|---|---|---|
| 1 | https://github.com/googlecreativelab/quickdraw-dataset | `data_set/quickdraw/subset/` (drawings), `data_set/quickdraw_repo/` (category list, license) | CC BY 4.0 | 7 NDJSON files, 500 recognized drawings each (circle, diamond, hexagon, octagon, square, star, triangle) |
| 2 | https://www.kaggle.com/datasets/reevald/geometric-shapes-mathematics | `data_set/kaggle_reevald/dataset/{train,val,test}/` | CC0 | 20,000 JPG 224x224 RGB, 8 classes x 2,500 (1,500 train / 500 val / 500 test) |
| 3 | https://data.mendeley.com/datasets/wzr2yv7r53/1 (El Korchi) | `data_set/2D geometric shapes dataset/output/` | CC BY 4.0 | 90,000 PNG 200x200 RGB, 9 classes x 10,000 |
| 4 | https://github.com/frobertpixto/hand-drawn-shapes-dataset | `data_set/github_handdrawn/data/user.*/images/` | CC BY 4.0 (data), MIT (code) | 27,292 PNG 70x70 RGBA, 4 classes (ellipse, rectangle, triangle, other) |

The El Korchi folder keeps its original name: a Windows file lock blocked
renaming it to `mendeley_elkorchi`. The build script uses the current name.

## Installed but excluded from the unified dataset

| Origin | Local folder | Why excluded |
|---|---|---|
| https://www.kaggle.com/datasets/dineshpiyasamara/geometric-shapes-dataset | `data_set/kaggle_dinesh/` (30,000 PNG 200x200 RGB: Circle, Square, Triangle x 10,000) | Kaggle license field reads "Unknown", and it adds only circle/square/triangle, which three other sources already cover. |

## Identified, evaluated, not downloaded

| Origin | Why not used |
|---|---|
| https://data.mendeley.com/datasets/d35tjjgjnx/1 | CC BY 4.0, but 380,000 synthetic images of 7 base shapes x property labels; no pentagon/hexagon/octagon, so no gap filled. |
| https://data.mendeley.com/datasets/ypfcrfxjgk/1 | CC BY 4.0, but 9,000 synthetic 64x64 images of circles, triangles, stripes, and background only. |
| https://www.kaggle.com/datasets/swastikarajkower/geometric-shapes-classification-dataset | Not an image dataset: a 1,200-row CSV of numeric shape measurements. License MIT (Kaggle API `licenseName`, checked 2026-11-20; the page description itself names none). |

## Removed duplicates (2026-10-19)

Each was verified identical to the copy kept, by MD5 of every file:

- `data_set/archive/` = `data_set/kaggle_dinesh/` (30,000 files)
- `data_set/test/` = `data_set/kaggle_reevald/dataset/test/` (4,000 files)
- `data_set/quickdraw-dataset-master/quickdraw-dataset-master/` (nested copy with `(2)` files)
- `data_set/Zip/` (5 raw zips, each entry-for-entry the same as its extracted folder)
